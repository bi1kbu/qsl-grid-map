## 3. API 路由

2026-11-17／0.0.25 起支持 QSL 2.x／3.x，`0.0.26` 仅调整切换成功提示时长，不改变以下路由。完整合同见[适配基线](qsl-v3-compatibility.md)。

本插件只提供一个 `CustomEndpoint（自定义端点）` API，另提供地图页面短路径。

| 方法 | 路径 | 认证要求 | 用途 |
| --- | --- | --- | --- |
| `GET` | `/apis/qsl-grid-map.bi1kbu.com/v1alpha1/map/page` | 匿名可访问 | 返回地图页面，3.x 可使用经验证的 `callsign（呼号或全站范围）` 参数 |
| `GET` | `/gridmap` | 匿名可访问 | 3.x 直接显示默认实例；2.x 返回 302 至固定完整地图页面 |
| `GET` | `/gridmap/{callsign}`、`/gridmap/all` | 匿名可访问 | 3.x 显示指定实例或全站地图；2.x 返回 404 |

短链接合同：

1. 原 API 的 `group（分组）= qsl-grid-map.bi1kbu.com`、`version（版本）= v1alpha1` 保持不变，短链接不注册新的 API group/version。
2. 保留实际 `contextPath（上下文路径）`；2.x 跳转目标固定为同站点地图页面，不透传查询参数。3.x 范围取自路径，不能通过查询参数覆盖。
3. `BeforeSecurityWebFilter（安全链前置过滤器）` 仅处理原页面 API、默认短路径及一个 ASCII 字母数字路径段的 GET；其他路径和方法交给 Halo，不增加匿名通配规则。
4. 服务端只读 Halo 插件版本元数据及现有地图设置，数据由浏览器直接请求所选版本的公开接口；不读取私有业务数据，不写入数据，无新增持久化字段。

不得存在的接口：

1. `/apis/qsl-grid-map.bi1kbu.com/v1alpha1/grids`
2. `/apis/qsl-grid-map.bi1kbu.com/v1alpha1/settings`
3. `/apis/qsl-grid-map.bi1kbu.com/v1alpha1/cache/refresh`
4. 任意自定义 `POST`、`PUT`、`PATCH`、`DELETE` 写入接口

## 4. 数据来源

依据 Halo 插件版本元数据选择公开接口，读取失败不回退另一版本。3.x 仅展示公开聚合，不读取完整 QSO；`showCallsigns（显示呼号）` 为真时才显示呼号行，全站没有单一本台位置。全站开放与单实例开关独立，计数不去重且含封锁实例；这些规则由 QSL 3 执行。

| 数据 | 来源接口 | 说明 |
| --- | --- | --- |
| 2.x 通联网格 | `/apis/api.qsl-management.bi1kbu.com/v1alpha1/qso-public/grids` | 浏览器直接请求，固定 `sceneType（场景类型）= QSO` |
| 3.x 通联网格 | `/apis/api.qsl.halo.run/v1alpha1/public-grid-map` | 浏览器直接请求，可选经验证的 `callsign（呼号或全站范围）`；要求 `schemaVersion（协议版本）= 1` |

两个数据源均不经过本插件服务端代理。本插件不再透传 `dateFrom（开始日期）`、`dateTo（结束日期）`、`grid（网格）`、`limit（明细数量上限）`，也不在前台提供对应筛选面板。

## 6. 菜单与权限

第一版不创建后台菜单，不创建角色模板，不创建自定义权限节点。

原因：

1. 无自定义后台管理页。
2. 无私有数据查询。
3. 无自定义写入接口。
4. 只展示 `qsl-management` 已公开数据。
5. 天地图凭据、共用地图显示及两种服务的独立缩放参数使用 Halo 插件设置能力，查看和编辑复用 Halo Console 既有权限映射与服务端鉴权，不引入前台配置写入能力。

## 7. 持久化模型

第一版不创建本插件自有业务 Extension 数据模型。

后台插件设置菜单顺序：

1. 地图显示：共用首选服务、中心网格、本台网格显示及边框颜色。
2. 天地图服务：凭据与天地图独立缩放参数。
3. OpenFreeMap 服务：OFM 独立缩放参数。

配置持久化：

| 配置项 | 存储机制 | 必填 | 说明 |
| --- | --- | --- | --- |
| `map.provider（首选地图服务）` | Halo `Setting + ConfigMap`，`map（地图显示）` 组 | 是，默认天地图 | `tianditu（天地图）` 或 `openfreemap（OpenFreeMap）`，缺省或非法值回退到天地图 |
| `map.defaultCenterGrid（默认中心网格）` | Halo `Setting + ConfigMap`，`map（地图显示）` 组 | 是 | 两种服务共用，默认 `OM89`，用于初始中心；2.x 同时用于本台标识，3.x 本台标识取当前实例公开响应，缺失或全站不绘制 |
| `map.showHomeGrid（显示本台网格位置）` | Halo `Setting + ConfigMap`，`map（地图显示）` 组 | 是 | 两种服务共用，默认开启 |
| `map.homeGridBorderColor（本台网格边框颜色）` | Halo `Setting + ConfigMap`，`map（地图显示）` 组 | 是 | 两种服务共用，默认 `#dc2626` |
| `tianditu.appKey（应用 key）` | Halo `Setting + ConfigMap`，`tianditu（天地图服务）` 组 | 否 | 用作天地图瓦片 `tk（应用令牌）` 参数；为空时直接使用 OpenFreeMap |
| `tianditu.secretKey（密钥）` | Halo `Setting + ConfigMap`，`tianditu（天地图服务）` 组 | 否 | 当前不输出到前台页面 |
| `tianditu.defaultZoom（默认缩放级别）` | Halo `Setting + ConfigMap`，`tianditu（天地图服务）` 组 | 是 | 默认 `3`，限制在该服务的有效缩放范围内 |
| `tianditu.minZoom（最小缩放级别）` | Halo `Setting + ConfigMap`，`tianditu（天地图服务）` 组 | 是 | 默认 `3`，允许范围 `1～18` |
| `tianditu.maxZoom（最大缩放级别）` | Halo `Setting + ConfigMap`，`tianditu（天地图服务）` 组 | 是 | 默认 `8`，允许范围 `1～18` |
| `openfreemap.defaultZoom（默认缩放级别）` | Halo `Setting + ConfigMap`，`openfreemap（OpenFreeMap 服务）` 组 | 是 | 默认 `3`，限制在该服务的有效缩放范围内 |
| `openfreemap.minZoom（最小缩放级别）` | Halo `Setting + ConfigMap`，`openfreemap（OpenFreeMap 服务）` 组 | 是 | 默认 `3`，允许范围 `1～18` |
| `openfreemap.maxZoom（最大缩放级别）` | Halo `Setting + ConfigMap`，`openfreemap（OpenFreeMap 服务）` 组 | 是 | 默认 `8`，允许范围 `1～18` |

两套缩放参数独立保存与规范化，不跨组读取或复制。任一组最小缩放大于最大缩放时，仅该组回退 `3～8`。所有缩放使用 Leaflet 级别，MapLibre GL Leaflet 自行换算。停止读取旧 `map.defaultZoom（默认缩放级别）`、`map.minZoom（最小缩放级别）` 与 `map.maxZoom（最大缩放级别）`，不增加兼容迁移层；升级后需在对应服务菜单重新保存自定义缩放，共用地图显示参数保持原位置。

运行时切换规则：

1. 首选天地图且已配置应用令牌时，加载 `vec_w（矢量底图）` 与 `cva_w（矢量注记）`；任一图层瓦片报错，或任一轮瓦片加载超过 15 秒，自动切换 OpenFreeMap。
2. 首选 OpenFreeMap 或未配置天地图应用令牌时，初始视图使用共用中心网格及 OFM 独立默认缩放。当前页面不反复切换服务；刷新后按后台首选服务重新选择。
3. 运行中兜底先移除天地图图层，再立即应用 OFM 缩放范围，然后等待 OFM 组件。保留当时中心点，缩放超出新范围时调整到最近边界；通联网格、本台网格及明细交互保留，本台网格位置与样式继续使用共用设置。数据成功、空数据或迟到响应均不重置当前视图。临时故障不改写持久化的首选服务。
4. 地图服务和数据接口提示独立维护，成功状态不得覆盖另一侧的错误。OpenFreeMap 每项组件静态资源加载限时 15 秒；开始加载地图样式后 20 秒仍未完成首次绘制时，显示慢加载提示并继续等待，完成绘制后恢复，不将其锁定为永久失败。
5. OpenFreeMap 地址固定为 HTTPS，保留 OpenFreeMap、OpenMapTiles 与 OpenStreetMap 署名；不增加服务端代理，不传递天地图密钥。
6. OpenFreeMap 先注册底层地图事件再请求样式，通过桥接库自定义署名选项保留完整来源；移除天地图图层先走 Leaflet 移除流程再解绑事件，确保旧图层事件与署名释放。WebGL 构造失败且底层实例不存在时，仅替换失败图层的安全移除钩子，再正常释放图层注册表、事件和容器，相关第三方缺陷防护维护条件见开发方案第 16 节。
7. 初始化、样式、瓦片和 WebGL 错误分别提示。瓦片错误以 `sourceId（数据源标识）+ canonical.z/x/y（规范瓦片级别与坐标）` 关联，同源同坐标的新瓦片对象成功后可解除旧错误，不同坐标或不同源同坐标成功均不误清；数据源错误由同源元数据成功解除。普通绘制完成或空闲事件不得清除仍未恢复的资源错误；WebGL 上下文恢复后先等待重新绘制，完成后才进入成功状态。
8. 控制台诊断仅输出阶段、白名单来源标识和状态码，不输出请求 URL、应用令牌或异常堆栈；网络变慢和外部服务故障仍取决于实际访问环境。
9. 切换成功提示从首次展示起保留 5 秒，后续加载或空闲事件不延长计时、不重新弹出；适用于失败、超时或缺少天地图令牌后的成功提示。到期按当前状态重新判断，不清除后来出现的地图错误或数据空态/错误，加载中和慢加载状态不适用 5 秒隐藏规则。
